Guide d'utilisation

Guide complet pour utiliser l'interface web ParkingLogicKit.

Télécharger le PDF

ParkingLogicKit permet de consulter l'état des parkings, de gérer les utilisateurs et de personnaliser l'affichage.

Rôle Pages accessibles Utilisation
Utilisateur Accueil, Dashboard, Compte, Paramètres, Thèmes Consulter les informations et gérer son compte.
Administrateur Pages utilisateur + Conducteurs, Véhicules, Badges, Associations Administrer les données utilisées par l'application.
  1. Aller sur la page Connexion.
  2. Saisir l'identifiant transmis par un administrateur.
  3. Saisir le mot de passe associé.
  4. Valider le formulaire pour entrer dans l'application.

En cas d'échec, vérifier les majuscules, les espaces en trop et demander à un administrateur de contrôler le compte.

Accueil

La page d'accueil affiche des cartes de navigation vers les pages autorisées.

Dashboard

Le dashboard affiche les places disponibles et l'état de chaque parking.

Compte

La page compte permet de modifier le prénom, le nom, l'identifiant, l'âge et le mot de passe.

Paramètres et thèmes

Ces pages servent à personnaliser l'interface sans modifier les données métier.

Conducteurs

Créer, modifier ou supprimer un utilisateur. La création peut aussi générer un badge, un véhicule et une association.

Véhicules

Ajouter, modifier ou supprimer les véhicules enregistrés : moto, voiture, camionnette ou camion.

Badges

Créer et supprimer les badges. Les associations sont gérées dans une page séparée.

Associations

Relier un conducteur, un badge et un véhicule pour rendre le lien plus clair.
Problème Solution conseillée
Impossible de se connecter Vérifier l'identifiant, le mot de passe, puis contacter un administrateur.
Une page n'apparaît pas Vérifier que le compte possède les permissions nécessaires.
Une association ne se crée pas Vérifier qu'un conducteur, un badge et un véhicule sont disponibles.
Le dashboard semble incorrect Rafraîchir les données avec le bouton prévu sur la page.
