Paramètres

Préférences locales de l'interface, sans modification des données métier.

Densité d'affichage

Choisir un affichage plus compact ou plus confortable.

Ce réglage change les espacements des tableaux, boutons, champs et en-têtes.

Taille du texte

Adapter légèrement la taille de l'interface selon le confort de lecture.

Le choix est appliqué à toute l'application via une variable CSS globale.

Animations

Réduire les transitions pour une interface plus directe.

Le mode réduit coupe les transitions CSS et les animations décoratives.

Aide contextuelle

Prévoir l'affichage de messages d'aide sur les pages complexes.

Ce bloc est un exemple: il disparaît si l'aide contextuelle est masquée.
